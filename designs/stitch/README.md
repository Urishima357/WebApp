## Arah desain

Pilihan pengguna: minimalis, retro custom, seluruh alur operasional, animasi lebih ekspresif. Cakupan mengikuti MVP/P0 PRD v1.2; bukan marketplace atau aplikasi native.

- Kanvas krem `#F6F3EC`, panel `#FFFEFA`, charcoal `#292D2C`.
- Aksi tembaga gelap `#914B2D`, sukses sage `#3E6655`.
- DM Sans untuk data/formulir; Barlow Condensed untuk judul dan merek.
- Revisi tipografi: font dasar ditetapkan melalui CSS atau kelas font body yang terdefinisi; fallback Arial/sans-serif. Referensi Stitch memakai Material Symbols, tetapi frontend terbaru memakai piktogram raster Canva sesuai permintaan pengguna.
- Identitas melalui fotografi motor custom, material metal/kulit, tanda dua garis pada merek; bukan ornamen di setiap komponen.
- Teks ringkas, satu aksi utama, rincian melalui tab/panel. Konfirmasi finansial dan validasi tetap jelas.

Preview inventaris sampel masih memperlihatkan tiga gambar gagal dimuat, terpisah dari koreksi tipografi.

## Cakupan dan verifikasi

Alur MVP/P0 diwakili melalui halaman, tab, dialog dan drawer: autentikasi, role, bengkel, showroom, pelanggan/motor terpadu, stok/movement, supplier/penerimaan, POS, empat metode pembayaran, nota A4, kontrol finansial, laporan, audit dan pengaturan. Beberapa state dikelompokkan dalam satu halaman; bukan setiap kombinasi role dan state memiliki artboard sendiri.

Screenshot representatif desktop/mobile ditinjau. Angka pendapatan Rp34.850.000 = bengkel Rp2.450.000 + barang Rp900.000 + motor Rp31.500.000; QRIS contoh Rp330.000 diperiksa pada HTML pilihan. Foto dan data seluruhnya contoh, bukan inventaris nyata. Desain tetap memerlukan review stakeholder: konsistensi semua foto/model, detail permission, istilah WO, field wajib dan aturan finansial di setiap tab belum diaudit menyeluruh.

HTML pilihan mengandung transisi CSS dan dukungan reduced motion. Animasi ekspresif belum diuji end-to-end; spesifikasi pada `MOTION.md` adalah acuan implementasi. Tidak ada klaim prototipe seluruh halaman sudah saling terhubung atau backend berfungsi.

Belum frontend produksi: belum ada autentikasi server, API, penyimpanan foto, gateway, validasi transaksi server atau uji aksesibilitas/responsivitas menyeluruh. Fitur P1/P2 seperti inquiry CRM, purchase approval, supplier return, profit lengkap, ekspor laporan, native mobile, WhatsApp otomatis dan marketplace tidak menjadi cakupan wajib desain ini.
